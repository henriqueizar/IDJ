## Dependências

**Ubuntu/Debian:**
```bash
sudo apt install build-essential libsdl2-dev libsdl2-image-dev \
                 libsdl2-mixer-dev libsdl2-ttf-dev
```

**macOS (Homebrew):**
```bash
brew install sdl2 sdl2_image sdl2_mixer sdl2_ttf
```

## Compilar e executar

```bash
make debug
./JOGO
```
